# 아이템 선택 기반 공 발사 기능 PRD

## 1. 문서 개요

- **문서 상태:** Draft
- **대상 프로젝트:** `LEC15_Game_Framework`
- **기준 문서:** `PRE_PRD.md`
- **목표:** 플레이 중 아이템 모드에서 발사할 공의 종류를 선택하고, 선택한 공을 플레이 모드에서 발사할 수 있도록 한다.

## 2. 배경과 문제 정의

현재 플레이 모드에서는 스페이스 키를 누르면 항상 작은 공만 발사된다. 사용자가 공의 종류를 선택할 수 없고, 플레이 중 선택 UI도 제공되지 않는다.

플레이 중 `i` 키로 아이템 모드에 진입하면 선택 UI를 표시하고, `0`, `1`, `2` 키로 발사 아이템을 선택할 수 있어야 한다. 아이템 모드에 진입한 동안에도 이미 발사된 공과 캐릭터의 상태 업데이트는 계속되어야 한다.

## 3. 목표와 범위

### 3.1 목표

1. 플레이 모드와 아이템 모드 사이를 `i` 키로 전환한다.
2. 아이템 모드에서 선택 가능한 공 목록과 현재 선택 상태를 화면 중앙에 표시한다.
3. 선택한 공의 종류에 따라 플레이 모드에서 다른 크기의 공을 발사한다.
4. 공 없음 상태에서는 스페이스 키를 눌러도 공이 생성되지 않도록 한다.
5. 아이템 모드가 게임 월드의 업데이트를 중단시키지 않도록 한다.

### 3.2 범위에 포함하지 않는 것

- 공의 공격력, 충돌, 점수, 적중 효과
- 공의 개수 제한이나 탄약 시스템
- 새로운 공 종류 추가
- 아이템 획득 및 인벤토리 저장
- 사운드, 이펙트, 네트워크 기능

## 4. 사용자 흐름

1. 게임 시작 시 플레이 모드로 시작한다.
2. 기본 선택 아이템은 작은 공이다.
3. 플레이 모드에서 스페이스 키를 누르면 선택된 아이템에 따라 공을 발사한다.
4. 플레이 모드에서 `i` 키를 누르면 아이템 모드로 전환한다.
5. 아이템 모드에서는 `item_select.png`를 화면 중앙에 표시한다.
6. 아이템 모드에서 `0`, `1`, `2` 중 하나를 누르면 선택 아이템을 변경한다.
7. 아이템 모드에서 `i` 키를 다시 누르면 플레이 모드로 돌아간다.
8. 아이템 모드에서 스페이스 키를 누르거나 이동 키를 눌러도 아이템 선택 외의 동작은 발생하지 않는다.
9. 아이템 모드에서 플레이 모드로 돌아온 뒤 스페이스 키를 누르면 현재 선택된 공을 발사한다.

## 5. 기능 요구사항

### FR-01. 아이템 모드 전환

- 플레이 모드에서 `i` 키를 누르면 아이템 모드로 전환한다.
- 아이템 모드에서 `i` 키를 누르면 플레이 모드로 복귀한다.
- 전환 시 캐릭터의 위치, 방향, 애니메이션 상태 및 현재 공의 위치를 초기화하지 않는다.
- `i` 키를 길게 누르거나 키 반복 입력이 발생해도 한 번의 의도하지 않은 다중 전환이 발생하지 않아야 한다.

### FR-02. 아이템 선택 UI

- 아이템 모드에서는 `item_select.png`를 화면 중앙에 표시한다.
- UI는 아이템 모드에서만 표시하고 플레이 모드에서는 표시하지 않는다.
- 현재 선택된 항목은 이미지가 제공하는 선택 표시를 활용하거나, 필요한 경우 기존 리소스 스타일을 해치지 않는 방식으로 명확히 표시한다.
- UI 표시로 인해 게임 월드의 캐릭터와 공 렌더링이 사라지거나 순서가 깨지지 않아야 한다.

### FR-03. 아이템 선택 입력

| 입력 | 선택 결과 |
|---|---|
| `0` | 공 없음 |
| `1` | 작은 공 |
| `2` | 큰 공 |

- 아이템 모드에서 유효한 선택 입력은 `0`, `1`, `2`뿐이다.
- 그 외 키 입력은 선택 상태나 게임 상태에 영향을 주지 않는다.
- 게임 시작 시 선택 상태는 작은 공(`1`)이어야 한다.
- 아이템 모드에서 선택이 변경되면 UI가 현재 선택을 반영해야 한다.

### FR-04. 공 발사

- 작은 공 선택 상태에서 플레이 모드의 스페이스 키는 `ball21x21.png` 기반의 작은 공을 발사한다.
- 큰 공 선택 상태에서 플레이 모드의 스페이스 키는 `ball41x41.png` 기반의 큰 공을 발사한다.
- 공은 캐릭터의 현재 위치와 바라보는 방향을 기준으로 발사한다.
- 공의 이동 방향과 기존 화면 밖 제거 동작은 유지한다.
- 공 없음 선택 상태에서는 스페이스 키를 눌러도 공 객체를 생성하지 않는다.
- 아이템 모드에서 스페이스 키를 눌러도 공을 발사하지 않는다.

### FR-05. 아이템 모드 중 월드 업데이트

- 아이템 모드에서도 캐릭터의 상태 업데이트를 계속 수행한다.
- 아이템 모드에서도 이미 발사된 공의 이동 및 화면 밖 제거를 계속 수행한다.
- 아이템 모드 진입 자체가 게임 월드의 객체를 일시정지시키거나 삭제하지 않는다.
- 아이템 모드에서 캐릭터 이동 입력은 무시할 수 있지만, 시간 기반 상태 변화 등 내부 업데이트는 계속되어야 한다.

## 6. 상태 및 구현 설계 기준

### 6.1 모드 상태

- `PLAY`: 캐릭터 입력, 아이템 발사, 월드 업데이트 및 렌더링
- `ITEM`: 아이템 선택 입력, 월드 업데이트 및 렌더링, 발사 입력 차단

아이템 모드는 별도 게임 프레임워크 모드로 구현하거나 기존 플레이 모드 내부 상태로 구현할 수 있다. 단, 두 방식 모두 `ITEM` 상태에서 `game_world.update()`가 계속 호출되어야 한다.

### 6.2 아이템 상태

권장 내부 값:

- `NONE`: 공 없음
- `SMALL_BALL`: 작은 공
- `BIG_BALL`: 큰 공

아이템 선택 상태는 플레이 모드와 아이템 모드 전환으로 초기화되지 않아야 하며, 프로그램 시작 시 `SMALL_BALL`로 초기화한다.

### 6.3 객체 책임

- **입력/모드 관리:** `i`, `0`, `1`, `2` 입력을 받고 모드를 전환한다.
- **아이템 UI:** `item_select.png` 로드 및 중앙 표시를 담당한다.
- **캐릭터:** 선택된 아이템을 전달받아 적절한 공을 생성한다.
- **공:** 이미지 종류를 보유하고 기존 속도, 방향, 화면 밖 제거 동작을 유지한다.
- **게임 월드:** 플레이·아이템 모드에서 공통으로 객체를 업데이트하고 렌더링한다.

## 7. 수용 기준

다음 항목을 모두 만족하면 기능을 완료한 것으로 본다.

- [ ] 게임 시작 직후 작은 공이 기본 선택되어 있다.
- [ ] 플레이 모드에서 스페이스 키를 누르면 작은 공이 발사된다.
- [ ] `i` 키로 아이템 모드에 진입하고 중앙에 `item_select.png`가 표시된다.
- [ ] 아이템 모드에서 `0`, `1`, `2`가 각각 공 없음, 작은 공, 큰 공으로 선택된다.
- [ ] 아이템 모드에서 다른 키 입력은 선택을 변경하지 않는다.
- [ ] 큰 공 선택 후 아이템 모드를 종료하고 스페이스 키를 누르면 큰 공이 발사된다.
- [ ] 공 없음 선택 후 아이템 모드를 종료하고 스페이스 키를 눌러도 새 공이 발사되지 않는다.
- [ ] 아이템 모드에서 스페이스 키를 눌러도 공이 발사되지 않는다.
- [ ] 아이템 모드에 있는 동안 이미 발사된 공이 계속 이동하고 화면 밖에서 제거된다.
- [ ] 아이템 모드에 있는 동안 캐릭터의 상태 업데이트가 계속된다.
- [ ] 아이템 모드 종료 후 캐릭터 위치·방향·선택 상태가 보존된다.
- [ ] 기존 `ESC` 종료/타이틀 전환 및 `P` 일시정지 동작이 회귀하지 않는다.
