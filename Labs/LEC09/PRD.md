# 애니메이션 뷰어 PRD

## 목표

pico2d로 스프라이트 시트(`sonic-sprite.png`)에 들어있는 모든 동작을 순서대로 재생하는 뷰어를 만든다.

## 범위

- 단일 파일 소스: `sonic_animation_viewer.py`
- 캔버스 크기: 800 x 600
- 대상 이미지: `sonic-sprite.png` (399 x 525)
- 프레임 좌표는 소스 코드 안에 직접 정의 (별도 JSON 없음)
- 종료: 창 닫기만 처리 (ESC 종료는 범위 외)

## 동작 규칙

1. 시트의 동작 12개를 순서대로 재생
2. 동작 하나당 5회 반복 -> 1초 대기 -> 다음 동작
3. 마지막 동작까지 다 재생하면 처음부터 무한 반복
4. 스프라이트는 기본 확대 배율의 1/4 크기로 그린다
5. 정지 동작(서기 등)은 화면 중앙에서 재생
6. 이동 동작(달리기: anim2, anim3, anim9)은 화면 왼쪽에서 오른쪽으로 가로지르며 이동 재생, 화면 밖으로 나가면 왼쪽 끝에서 다시 등장

> 참고: 스프라이트 10개 행 중 8행·10행의 끝 2칸씩은 각각 다른 동작이다. 기존 10개 동작(8행·10행은 앞부분만) + 신규 2개 = **총 12개 동작**으로 재생한다. (동작11 = 8행 끝 2칸, 동작12 = 10행 끝 2칸)

## 개발 방식

기능 단위로 잘게 나누어 개발한다. 각 단계마다 동작 확인 후 커밋. 단계는 20개 이상.

## 완료 기준

- [ ] 캔버스가 800 x 600으로 열림
- [ ] 모든 동작이 순서대로 재생됨

- [ ] 마지막 동작 이후 처음으로 돌아가 무한 반복함
- [ ] 스프라이트 크기가 화면 대비 적절함 (기존의 1/4 수준)
- [ ] 정지 동작은 화면 중앙에서 재생됨
- [ ] 이동 동작(anim2, anim3, anim9)은 화면을 가로지르며 재생됨
- [ ] 창 닫기로 정상 종료됨 (ESC 처리 없음)
- [ ] 커밋이 20개 이상 쌓임
