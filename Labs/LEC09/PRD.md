# 애니메이션 뷰어 PRD

## 목표

pico2d로 스프라이트 시트(`sonic-sprite.png`)에 들어있는 모든 동작을 순서대로 재생하는 뷰어를 만든다.

## 범위

- 단일 파일 소스: `sonic_animation_viewer.py`
- 캔버스 크기: 800 x 600
- 대상 이미지: `sonic-sprite.png` (399 x 525)
- 프레임 좌표는 소스 코드 안에 직접 정의 (별도 JSON 없음)
- 종료: 창 닫기만 처리 (ESC 종료는 범위 외)

## 동작 규칙

1. 시트에 있는 모든 동작 애니메이션을 순서대로 재생
2. 동작 하나당 5회 반복 -> 1초 대기 -> 다음 동작
3. 마지막 동작까지 다 재생하면 처음부터 무한 반복
4. 캐릭터가 화면(800x600) 중앙에 항상 오도록 재생 (보이도록 확대)

> 참고: 시트는 제목/크레딧 텍스트를 제외하면 스프라이트가 10개 행으로 나뉘고, 달리기 등은 여러 행에 반복된다. 동작(애니메이션) 단위 구분은 개발 중 프레임을 직접 확인해 확정한다. (현재 추정 8~9개)

## 개발 방식

기능 단위로 잘게 나누어 개발한다. 각 단계마다 동작 확인 후 커밋. 단계는 20개 이상.

| # | 단계 | 커밋 메시지 예시 |
| - | ---- | ---------------- |
| 1 | 캔버스 골격 | `ai - feat: 캔버스 800x600 생성 및 메인 루프 골격` |
| 2 | 종료 처리 | `ai - feat: 창 닫기 이벤트로 종료 처리` |
| 3 | 배경 초기화 | `ai - feat: clear_canvas 배경 초기화 추가` |
| 4 | 이미지 로드 | `ai - feat: sonic-sprite.png 이미지 로드` |
| 5 | 1회 그리기 | `ai - feat: 캐릭터 화면 중앙에 1회 그리기` |
| 6 | 프레임 그리기 함수 | `ai - feat: 좌표 기반 프레임 그리기 함수 작성` |
| 7 | 좌표 테이블 구조 | `ai - feat: 동작별 프레임 좌표 테이블 구조 작성` |
| 8 | 동작1 좌표 | `ai - feat: 동작1 프레임 좌표 작성` |
| 9 | 동작2 좌표 | `ai - feat: 동작2 프레임 좌표 작성` |

| 11 | 동작4 좌표 | `ai - feat: 동작4 프레임 좌표 작성` |
| 12 | 동작5 좌표 | `ai - feat: 동작5 프레임 좌표 작성` |
| 13 | 동작6 좌표 | `ai - feat: 동작6 프레임 좌표 작성` |
| 14 | 동작7 좌표 | `ai - feat: 동작7 프레임 좌표 작성` |
| 15 | 동작8 좌표 | `ai - feat: 동작8 프레임 좌표 작성` |

| 17 | 동작 간 전환 | `ai - feat: 한 동작 재생 후 다음 동작으로 전환` |
| 18 | 5회 반복 | `ai - feat: 동작 5회 반복 재생 처리` |
| 19 | 1초 대기 | `ai - feat: 동작 사이 1초 대기 처리` |
| 20 | 무한 반복 | `ai - feat: 마지막 동작 후 처음부터 무한 반복` |

| 23 | 타이밍 점검 | `ai - fix: 반복/대기 타이밍 오차 수정` |
| 24 | 정리 | `ai - refactor: 종료 시 자원 정리 및 상수 정리` |
